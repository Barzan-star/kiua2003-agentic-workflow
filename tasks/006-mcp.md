# Task 006: W43 custom MCP forecast demonstration

The demonstration exposes one read-only `forecast(hours=24)` MCP tool backed by
the saved MET Norway fixture. It returns at most 24 compact historical forecast
rows beginning at the fixture's first timestamp. Those saved entries are not
current weather or observations, and the entry limit does not guarantee a
duration in hours. The server runs offline and does not refresh or write files.

From the repository root, start Codex with the demo server enabled:

```sh
codex -c 'mcp_servers.met.enabled=true'
```

MET Norway data is provided under CC BY 4.0. See the API
[terms of service](https://api.met.no/doc/TermsOfService).
