# Task 008: Offline GitHub Actions CI

## Goal
Add a GitHub Actions workflow that checks the repository on pull requests and
pushes to `main`. The job uses the supported Python and MCP dependency setup,
and runs the offline, dry-run, syntax, unit, and fixture-integrity checks.

## Requirements
- Name the workflow `checks`; trigger it on `pull_request` and pushes to
  `main`.
- Run one job on `ubuntu-24.04`, with a five-minute timeout and
  `contents: read` permission.
- Use `actions/checkout@v7` with `persist-credentials: false` and
  `actions/setup-python@v7` with Python `3.12`.
- Create `.venv` using `python -m venv .venv` and install
  `requirements-mcp.txt` through `.venv/bin/python -m pip`.
- Explicitly verify that the MCP SDK imports successfully, so MCP tests cannot
  be silently skipped because the dependency is missing.
- Run named steps for `bash -n harness/run.sh`, both runner dry-runs, the
  offline probe, its checker, unittest discovery, `git diff --check`, and
  `git diff --exit-code -- fixtures/`. Any failure fails the job.
- Keep CI offline with respect to fixture and mocked inputs: no Codex
  installation, model calls, live MET requests, repository secrets, or
  schedules. Dependency installation may download packages.
- Document workflow triggers, checks, and local reproduction commands in the
  README, including that offline does not mean dependency installation is
  network-free.

## Acceptance
- Inspect `.github/workflows/checks.yml` to confirm the required triggers,
  permissions, actions, setup, and named checks.
- Follow the documented local reproduction commands.
- `git diff --check` succeeds.
- `git diff --exit-code -- fixtures/` succeeds.
